# realtime-collab-board
A Real-Time Collaboration Board (Trello-like)

A full-stack real-time collaboration board built using **Angular**, **Spring Boot**, **Kafka**, and **MongoDB**.
The app supports creating boards, lists, and cards with instant updates across users using a WebSocket-based notification service.
Kafka powers the event streaming pipeline, ensuring scalable and reliable real-time collaboration, while MongoDB stores all board data and activity logs.
